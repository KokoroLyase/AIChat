# 智信 AIChat 隐私说明（草稿）

状态：草稿，从 0.4.0 开始维护，1.0.0 时定稿。每新增一个要连接的服务器或一类本地数据，都在这里记一笔。

## 概述

智信没有账号系统，也没有自己的服务器。App 不收集统计数据，不做崩溃上报，不放广告。

## 保存在手机上的数据

| 数据 | 位置 | 保护方式 |
| --- | --- | --- |
| 联系人、会话、聊天记录、记忆、用量统计、服务商配置 | 应用私有目录的 Room 数据库 | 系统的应用隔离和全盘加密；App 没有另外加密 |
| 聊天图片、头像 | 应用私有目录 `files/images`、`files/avatars` | 同上 |
| 设置（深色模式、字体大小、昵称、头像路径、更新检查状态等） | 应用私有目录的 MMKV | 同上 |
| API Key | 服务商配置表 | Android Keystore 加密后存放 |
| 崩溃日志（0.4.0） | 应用私有目录 `files/logs`，最多 20 份 | 系统的应用隔离和全盘加密；内容见下 |
| 分享崩溃日志时的副本（0.4.0） | 应用缓存 `cache/crash-exports`，只有一份 | 下次分享时覆盖；目前清理缓存和清空日志都不删除它 |
| 恢复前的临时备份（0.4.0 起恢复成功后立即删除） | 应用私有目录 `files/backups` | 恢复进行中或失败时才存在 |
| 恢复时的解密临时文件（0.4.0） | 应用缓存 `cache/restore` | 恢复结束即删除，下次启动也会清理 |

系统自动备份已关闭（`allowBackup=false`），这些数据不会经系统备份离开手机。卸载 App 会清除全部本地数据。

**对外不能写成“数据已加密”：** App 自己加密的只有 API Key 和设了密码的导出文件。

## 崩溃日志的内容

每份包括：时间、App 版本、设备型号、系统版本、崩溃类型（Java/Kotlin、ANR、原生）和堆栈。

不包括：异常说明（message）、聊天内容、记忆、提示词、图片内容和 API Key。ANR 只保留本 App 主线程的调用栈；原生崩溃只记录类型和时间，不解析符号。

日志只保存在本机，App 不会自动上传。用户在日志详情点“分享这份日志”时，才会由系统分享给用户选择的 App。

## 离开手机的数据

| 去向 | 什么时候 | 内容 |
| --- | --- | --- |
| 用户配置的模型服务商（用户自己填写 Base URL 和 Key） | 发送消息、重新生成、生成记忆、测试连接、获取模型列表 | 系统提示词、记忆、上下文范围内的聊天记录、最近的图片、模型参数和 API Key；具体内容由服务商的隐私政策约束 |
| GitHub（`api.github.com` 和 Release 下载地址） | 启动时检查更新（24 小时最多一次，可关闭）、手动检查、下载更新 | 普通 HTTP 请求，不带聊天数据；GitHub 能看到设备 IP |
| 用户自己选择的位置 | 用户导出数据 | 备份文件；不设密码时是明文 zip，设密码时整个文件加密 |
| 用户自己选择的 App | 用户分享崩溃日志 | 这一份日志 |

API Key 只发给请求格式和完整 Base URL 都相同的服务商。

## 导出文件

- 不设密码：普通 zip，拿到文件的人都能打开聊天记录和图片。
- 设密码：整个文件用 AES-256-GCM 分块加密，密钥由密码经 PBKDF2-SHA256（31 万次）派生。忘记密码无法恢复。
- 包含 API Key 时必须设密码。

## 权限

| 权限 | 用途 |
| --- | --- |
| 网络 | 连接用户配置的服务商和 GitHub |
| 通知 | 回复到达时提醒 |
| 前台服务（数据同步） | 等待回复较久时继续请求 |
| 安装应用 | 应用内更新时拉起系统安装界面 |

相册和拍照使用系统选择器和系统相机，不申请存储和相机权限。文件导入导出使用系统文件选择器。
