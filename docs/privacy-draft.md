# 智信 AIChat 隐私说明（草稿）

状态：草稿，内容对照 0.9.0 的代码（标“0.5.0 起”“0.6.0 起”“0.7.0 起”“0.7.1 起”“0.7.2 起”“0.8.0 起”“0.9.0 起”的是那一版新增的），1.0.0 时定稿。每新增一个要连接的服务器或一类本地数据，都在这里记一笔。未来版本的事项集中放在文末“待定稿”。

## 概述

智信没有账号系统，也没有开发者服务器。App 不收集统计数据，不做崩溃上报，不放广告，也不会把数据上传给开发者。

数据保存在手机上。只有下文“离开手机的数据”列出的情况，内容才会发到别处，其中聊天内容只发给用户自己配置的模型服务商；0.7.0 起，用户使用语音消息时，录音和联系人的回复文字还会发给用户自己配置的语音识别、语音合成服务商；0.7.1 起也可以改用本机的系统语音合成和离线识别，这时录音和回复文字不离开手机（离线识别的模型要先从魔搭社区下载一次）。0.8.0 起用户和联系人语音通话时，说的每一段话发给语音识别来源，联系人的回复文字发给语音合成来源，规则和语音消息相同。0.9.0 起用户点“翻译”时，这条消息的文字发给这个联系人所用的模型服务商；收藏、引用和复制不联网（复制的文字放进系统剪贴板，由系统管理）。

0.6.0 起有一种情况是**没有用户操作时**发生的：用户为某个联系人开启“主动聊天”后，App 会在后台自动把这个联系人的聊天内容发给它的服务商。这个功能默认关闭，详见下文。

## 崩溃日志的内容

每份包括：时间、App 版本、设备型号、系统版本、崩溃类型（Java/Kotlin、ANR、原生）和堆栈。

不包括：异常说明（message）、聊天内容、记忆、提示词、图片内容和 API Key。ANR 只保留本 App 主线程的调用栈；原生崩溃只记录类型和时间，不解析符号。

日志只保存在本机，App 不会自动上传。用户在日志详情点“分享这份日志”时，才会由系统分享给用户选择的 App。独立日志页不向其他 App 导出，桌面快捷方式由系统启动。

服务商收到数据后如何处理，由该服务商的隐私政策约束。

**全局记忆会发给多家服务商（0.5.0 起）：** 全局记忆不属于某一个联系人，每个开启“使用全局记忆”的联系人都会在请求里带上它，所以它会发给**每个开启它的联系人所用的服务商**；联系人用的服务商不同时，同一份内容会发给多家。新联系人和升级前已有的联系人都默认开启（用户决定），全局记忆为空时不发送任何内容。“我 → 全局记忆”页写明了这一点，并列出当前会发给哪些服务商；可以单条关闭、在联系人编辑页逐个关闭，或在该页一次关闭所有联系人。总结和合并记忆（0.7.2 起是整理核心记忆）的请求不带全局记忆。不额外调用模型挑选要发送的条目。

**主动聊天会在没有操作时发送聊天内容（0.6.0 起）：** 默认关闭，新联系人和升级前已有的联系人都要由用户在联系人编辑页手动开启；第一次开启时弹窗说明它会自动调用模型、消耗 API 额度。开启后，App 用系统后台任务大约每 15 分钟检查一次（回到前台时也查一次），时机合适就把上表所列内容发给这个联系人的服务商；每天的调用次数有上限（默认 20 次，所有联系人合计），免打扰时段（默认 23:00～7:00）不调用，连续 2 次主动发送没有得到回复后暂停。开启主动聊天的联系人，普通聊天的系统提示词里多一段“怎么记下约定时间”的说明；模型据此写在回复里的隐藏标记只在本机解析，记下的时间和事由不离开手机（到点时事由会随那次主动请求发回同一个服务商）。关闭开关、或全部联系人都关闭后，后台任务取消，不再有任何自动发送。恢复 0.5.0 及更早的备份后，联系人的主动聊天都是关闭的；恢复 0.6.0 的备份后，备份里开着的联系人仍然开着。“我 → 主动聊天”显示今日已用次数、最近一次检查时间和每个联系人的状态。

**API Key 的去向：** Key 只随请求发给它所属服务商当前配置的 Base URL，请求不跟随重定向。用户修改已保存服务商的地址又没有填新 Key 时，0.4.2 起要先确认 Key 会发给新地址，确认后 Key 保留并发给新地址（0.4.1 及更早没有这个提示）。恢复备份时，只有请求格式和完整 Base URL 都相同才算同一个服务商，才会复用本机已保存的 Key。

**语音服务商的预置（0.7.2 起）：** 语音合成预置火山引擎（豆包，`openspeech.bytedance.com`）、阿里云百炼（千问，用户自己的业务空间地址 `*.cn-beijing.maas.aliyuncs.com`）、BigModel（智谱，`open.bigmodel.cn`）、Xiaomi MiMo、MiniMax（`api.minimax.cn`）、Fish Audio（`api.fish.audio`，服务器在海外）、硅基流动和 OpenRouter（`openrouter.ai`，服务器在海外）；语音识别预置火山引擎、百炼、智谱、MiMo、Fish Audio、硅基流动和 OpenRouter。都只在用户选用、填了 Key 后才连接，规则和 0.7.0 的语音服务商相同：Key 只发到它自己的地址、不跟随重定向。百炼合成用流式返回，不去下载它给的另一个域名上的音频链接；MiniMax 也直接要音频数据，不用下载链接。智谱一次只识别 30 秒，更长的录音切成几段分别上传，后一段带上前面识别出的文字。OpenRouter 是转发平台：要合成的文字和要识别的录音会由它转给用户所选模型背后的服务商（比如 Google、OpenAI），这些服务商怎么处理数据要看 OpenRouter 和它们各自的政策；App 不发 OpenRouter 的来源标识请求头。聊天用的百炼预置也改用业务空间地址，已保存的连接不动。0.7.2 起大语言模型的预置加了火山引擎（豆包，火山方舟 `ark.cn-beijing.volces.com`）和 MiniMax（`api.minimax.cn`），同样只在用户添加、填了 Key 后才连接，发送的内容和其他模型服务商相同。

**语音消息（0.7.0 起）：** 语音由用户主动使用：按住说话、输入框旁的麦克风，或把消息发送类型设成“语音”。第一次按住说话或录音转文字前，App 会说明录音要发给哪个语音识别服务商（写出它的名称）；语音合成和识别的服务商都在“我 → 语音消息”里单独选择、填写 Key，和联系人的大语言模型服务商可以是不同的几家；0.7.2 起还可以在联系人资料里给某个联系人单独选，和他聊天时用他的，单独选的用不了时不会改发给全局选的服务商。没设置语音合成时联系人一律回文字；合成失败时这一段改发文字，不再请求模型，也不再请求合成。语音服务商的 Key 和大语言模型的一样只发到它自己的 Base URL、不跟随重定向。识别和合成按服务商的规则收费，用量统计里单独记字数和秒数。0.7.1 及更早不做试听；0.7.2 起选音色页可以试听，只有用户点了“试听”才合成一句固定的话（可能计费，不计入用量统计），选系统语音时在手机上合成。debug 和 perf 测试包可以用应用私有目录里的一段预置音频代替麦克风（正式版里这个开关是关的），只用于测试。

**语音通话（0.8.0 起）：** 通话由用户主动发起（联系人资料或聊天页“+”里的“语音通话”），App 不会自己打电话。第一次通话前会说明录音发给哪个识别来源、回复文字发给哪个合成来源（本机来源时写明不离开手机）、每一轮还会请求联系人的模型。通话期间麦克风一直开着，但只有判断为说话的那几段会被识别和保存；判断用随安装包提供的 Silero VAD 模型（Silero Team，MIT 许可，k2-fsa 转换的 ONNX 格式）在手机上运行，不联网、不另外下载，不支持的手机改用音量判断。联系人单独选的识别、合成来源用不了时不能通话，不会改发给全局选的服务商。切到后台或锁屏时通话继续，这期间显示语音通话的常驻通知（见下面“通知”）；挂断、连续失败、单次 60 分钟、5 分钟没人说话、来电或麦克风出错时结束，麦克风和放音随之关闭。

**本机语音（0.7.1 起）：** 语音合成和识别的服务商列表上面有“本机”一组，选用后不需要 Key、不连服务商。系统语音合成把联系人的回复文字交给手机里的语音合成引擎（见上表），只列出不需要联网、已经装好的中文音色。离线识别用随安装包提供的 sherpa-onnx 在手机上识别，录音不离开手机；模型由用户在离线识别页主动下载，下载前写明大小（约 239.5 MB）、来源（魔搭社区）并提示用 Wi-Fi，按流量计费的网络下额外提醒；模型只在应用私有目录，不随备份导出，可以单独删除。第一次按住说话前的说明在离线识别时写明录音不离开手机。本机合成和识别都不计入用量统计。下载时的进度通知不含任何聊天内容。

**通知：** 回复到达时，通知内容由系统显示。关闭“内容预览”后，通知只显示“发来一条新消息”。开启“消息免打扰”的聊天不发回复通知。0.6.0 起主动消息的通知规则相同；“消息免打扰”只是不发通知，不会让联系人停止主动聊天。0.7.0 起语音消息在通知里显示为“[语音]”；长按语音选“后台播放”时显示一条常驻通知“正在后台播放语音”，不含联系人和消息内容，放完自动消失。0.8.0 起通话期间显示常驻通知“正在和 X 语音通话”（关闭“内容预览”时不写联系人名称），带“挂断”，挂断后消失；通话消息在聊天列表里显示为“[通话]”和时长。

## 导出文件

- 不设密码：普通 zip，拿到文件的人都能打开聊天记录、图片、聊天背景和全局记忆（0.5.0 起）。API Key 不导出。
- 0.6.0 起导出联系人的主动聊天开关和频率、免打扰时段和每日上限；今日已用次数、暂停状态、约好的提醒和上次主动请求的结果不导出。
- 0.7.0 起导出语音消息的文件（`voice/` 目录）和转写文字、联系人的消息发送类型、音色和语气风格、语音合成和识别服务商（Key 同样默认不导出）以及选用的服务商；不设密码时，拿到文件的人也能听到这些语音。
- 0.7.1 起选用的本机来源（系统语音、离线识别）也随“选用的服务商”导出；离线识别模型和系统语音合成选的音色不导出。
- 0.7.2 起导出时可以只选其中几项（联系人、聊天记录、联系人记忆、用量统计、全局记忆、模型配置、回复偏好、主动聊天设置、语音消息设置、个人资料和外观），没选的不写进文件；API Key 只在选了模型配置时才可能导出。选了联系人或语音消息设置、没选模型配置时，文件里记下它们用到的服务商的请求格式和地址（不含名称、模型和 Key），恢复时用来找本机的同一个服务商。记忆带“是否核心记忆”；联系人带单独设置的回复偏好和单独选的语音合成、识别来源。
- 0.8.0 起导出语音通话：通话的时长、每一句的文字和录音、合成的语音（`calls/` 目录），跟着“聊天记录”；不设密码时，拿到文件的人也能听到这些录音。
- 0.9.0 起导出收藏（单独的“收藏”项，默认选中）：收藏的文字、通话的每一句和复制的录音（`favorites/` 目录）；不设密码时，拿到文件的人也能看到和听到。消息的引用和译文跟着“聊天记录”。
- 设密码：整个文件用 AES-256-GCM 分块加密，密钥由密码经 PBKDF2-SHA256（31 万次）派生。忘记密码无法恢复。
- 包含 API Key 时必须设密码。

## 权限

| 权限 | 用途 |
| --- | --- |
| 网络（`INTERNET`） | 连接用户配置的服务商和 GitHub；0.7.1 起用户下载离线识别模型时连接魔搭社区 |
| 通知（`POST_NOTIFICATIONS`） | 回复到达时提醒；第一次发消息时申请；0.6.0 起第一次开启主动聊天时也会申请 |
| 麦克风（`RECORD_AUDIO`，0.7.0 起） | 按住说话和录音转文字；第一次使用时申请，拒绝后说明并给出系统设置入口。只在用户按住或点了录音时录，松开或点完成就停。0.8.0 起语音通话期间一直开着，挂断就停 |
| 麦克风类前台服务（`FOREGROUND_SERVICE_MICROPHONE`，0.8.0 起） | 语音通话时切到后台或锁屏也接着听和放（同一个前台服务也用媒体播放类型）；只在通话页在前台、发起通话时启动，挂断时停止 |
| 媒体播放前台服务（`FOREGROUND_SERVICE_MEDIA_PLAYBACK`，0.7.0 起） | 长按语音选“后台播放”时，回到桌面也接着放；只在这期间运行 |
| 修改音频设置（`MODIFY_AUDIO_SETTINGS`，0.7.0 起，安装时自动授予） | 长按语音选“听筒播放”时把声音切到听筒，放完恢复；0.8.0 起语音通话期间切到通话模式，在听筒、耳机和扬声器之间切换，挂断后恢复 |
| 前台服务（`FOREGROUND_SERVICE`、`FOREGROUND_SERVICE_DATA_SYNC`） | 等待回复时让请求在后台继续；0.5.0 起，一次回复的几条还要等一会儿才送达时，也让投递在后台继续；0.7.1 起下载离线识别模型时显示带进度的常驻通知，回到桌面也接着下 |
| 安装应用（`REQUEST_INSTALL_PACKAGES`） | 应用内更新时拉起系统安装界面 |
| `isomeria.aichat.DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION` | AndroidX 依赖库自动加入、只给 App 自己用的签名级权限，用来保护只在 App 内部用的广播接收器；安装时自动授予，不涉及用户数据，别的 App 拿不到 |
| `ACCESS_NETWORK_STATE`、`WAKE_LOCK`、`RECEIVE_BOOT_COMPLETED` | 由 WorkManager 依赖库加入，用于调度后台任务；0.6.0 起主动聊天的周期检查和约定提醒也靠它们。0.6.0 没有新增权限，不使用精确闹钟；0.7.0 新增的权限见上；0.7.1 没有新增权限（下载模型用已有的数据同步前台服务）；0.7.2 没有新增权限；0.8.0 新增的权限见上；0.9.0 没有新增权限 |

相册和拍照使用系统选择器和系统相机，不申请存储和相机权限。文件导入导出使用系统文件选择器，保存图片到相册也不需要存储权限。
