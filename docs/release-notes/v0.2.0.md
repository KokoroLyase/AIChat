智信 0.2.0：数据与更新。

- 导出数据：联系人、聊天记录、头像、聊天图片和设置导出为一个 zip 文件，保存位置用系统文件选择器选。默认不含 API Key；勾选「包含 API Key」时需要设置密码，Key 加密后才放进文件
- 恢复数据：可选「合并」或「覆盖」。恢复前会自动备份当前数据，恢复失败时自动撤销；来自更新版本的备份会提示先升级
- 检查更新：启动时自动检查（每天最多一次，可在设置里关闭），也可以在「设置 → 关于」里手动检查；发现新版本时可以立即更新、稍后提醒或忽略此版本
- 聊天信息：聊天页右上角「···」进入，可以置顶聊天、查找聊天记录、清空聊天记录
- 搜索：同时搜索联系人和聊天内容，点结果直接跳到那条消息并高亮
- 表情面板：系统自带的全部 emoji，按分类排列，带「最近使用」；面板和键盘一样高，切换时输入栏不跳动
- 草稿：退出聊天时保存没发出去的文字，聊天列表里显示红色「[草稿]」
- 设置里新增「清空所有聊天记录」

需要 Android 14 及以上。从 0.1.0 直接覆盖安装即可，数据会保留。
