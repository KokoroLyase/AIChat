# 智信 0.3.1

- 新增 DeepSeek、阿里云百炼（千问）、智谱、Kimi、Xiaomi MiMo、硅基流动、OpenRouter 七家连接预置，保留自定义兼容接口。
- 不再内置具体型号；获取模型列表后按需补齐能力、思考档位和温度规则，也可手动添加。列表成功不代表聊天已经验证。
- 思考支持实际完整原生档位、仅开关和始终开启；温度可调、固定或省略，模型支持单独覆盖兼容字段并恢复继承。
- 刷新保留手动、已配置和正在使用的模型，不自动切换默认；参数冲突提示受影响联系人，保留原值并在请求前校验。
- 联系人记忆可独立选择同服务商模型和思考强度；记忆任务按联系人串行，全局最多并行两个，并显示排队、生成和最近结果。
- 数据库和备份升级至 v3，保留旧配置、Key 密文及旧请求行为，支持 v1/v2 逐版迁移。
- 修正 URL 路径大小写比较，避免恢复备份时错误复用 Key；修复模型列表响应在主线程读取的问题。

上下文、记忆阈值/预算/合并策略、历史思考不回传和用量归类保持原规则。本版不含语音、订阅或其他原生 API 协议。
