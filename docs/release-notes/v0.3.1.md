# 智信 0.3.1

- 新增 DeepSeek、阿里云百炼（千问）、智谱、Kimi、Xiaomi MiMo、硅基流动、OpenRouter 七家连接预置，保留自定义兼容接口。
- 不再内置具体型号；获取模型列表后按需补齐能力、思考档位和温度规则，也可手动添加。列表成功不代表聊天已经验证。
- 思考支持实际完整原生档位、仅开关和始终开启；温度可调、固定或省略，模型支持单独覆盖兼容字段并恢复继承。
- 刷新保留手动、已配置和正在使用的模型，不自动切换默认；保存规则时只有这次新造成的参数冲突才要确认，原有冲突只作提示，联系人原值保留并在请求前校验。
- 联系人记忆可独立选择同服务商模型和思考强度；记忆任务按联系人串行，全局最多并行两个，并显示排队、生成和最近结果。
- 数据库和备份升级至 v3，保留旧配置、Key 密文及旧请求行为，支持 v1/v2 逐版迁移。
- 修正 URL 路径大小写比较，避免恢复备份时错误复用 Key；修复模型列表响应在主线程读取的问题。


界面和使用体验：

- 模型列表分成已配置和待配置，每个模型压成一行；模型超过 20 个时显示搜索框，待配置默认折叠。
- 未保存就返回会先询问；移除模型和档位要确认；获取列表失败时说明具体原因，保存成功有提示。
- 配置行和表单放得下时左右排，放不下才换行；App 内字体大小对弹窗和菜单也生效。
- 温度恢复原有滑块，按 0.1 吸附；固定和不发送的温度各有一行；高级设置显示友好名称和实际字段名。
- 联系人的当前模型待配置时，也可以先改名、改提示词，并能直接进入这个模型的配置页；配置好之前聊天仍会被拦下，不发请求。
- 记忆页分成记忆设置、任务状态和已有记忆，手动总结期间不能重复触发。
- 提高错误和成功文字的对比度，扩大小按钮的点击区域，补充读屏说明。

上下文、记忆阈值/预算/合并策略、历史思考不回传和用量归类保持原规则。本版不含语音、订阅或其他原生 API 协议。

七家预置目前只用模拟接口测试过，没有用真实服务商逐家验证，遇到不兼容的情况可以在模型配置里手动调整。

需要 Android 14 及以上。从 0.3.0 覆盖安装即可，已有的服务商、联系人和记忆会自动保留。
