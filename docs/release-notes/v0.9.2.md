# 智信 0.9.2（草稿）

还没发布

- **DeepSeek 语音**：语音合成和语音识别的预置服务商里加了 DeepSeek，排在最前面。用 DeepSeek 开放平台的 API Key，不用填模型；合成有海星（女，默认）和暗潮（男）两种音色，没有语气和风格设置。
- **时间信息**：每次请求回复时，App 会在你最新的消息前面加一行只给模型看的附注，写明现在的日期、星期、时间，以及距离上一条消息过了多久（不管是谁发的），回复能更贴合你此刻的情况。这行附注不显示、不保存。默认开启，升级上来的也开启；可以在“我 → 通用设置 → 发送时附带时间信息”里关掉，关掉后请求里不带任何时间。
- **发送文件**：聊天页“+”里多了“文件”，可以发 PDF、Word、PPT、Excel 和图片，一次可以选多个，每个最大 200 MB。文件先交给 MinerU 解析成文字，联系人就能读到文件的内容；最近 3 个文件带全文，更早的只带文件名。要先在“我 → 模型服务 → 文件解析”里填 MinerU 的 Token 并启用，没配置时“文件”是灰的。文件显示为卡片，写着名称、大小和类型，解析中显示“解析中…”；点卡片用手机里的其他 App 打开；解析失败时点感叹号重试。文件不能收藏、引用和翻译。
- **不能看图的模型也能收图片**：联系人的模型不能看图时，如果配好了文件解析，“相册”和“拍照”可以用了，图片会先交给 MinerU 识别出文字再发给模型。模型能看图时照旧直接发图片。
- **不再显示“对方正在输入…”**：等联系人回复时，聊天页标题照旧是联系人名称，和平时一样；回复到了直接出现。等待中仍可以长按自己的消息取消回复。
- **界面**：“+”面板多了一项，窄屏加特大字体放不下时换到第二行，面板可以上下滑。

**费用和隐私：** 文件，以及不能看图的模型收到的图片，会上传到 MinerU 的服务器（mineru.net 和它的对象存储、下载地址）解析，MinerU 按每天的页数给额度；解析出的文字之后随聊天记录发给联系人的模型，文件越长，请求用的 token 越多。DeepSeek 语音按 DeepSeek 的价格收费。时间附注每次请求多几十个字。没有新增权限。

**升级后的变化：** 数据库和备份格式升到 v11。0.9.2 能恢复以前各版本的备份；0.9.1 及更早的版本打不开 0.9.2 导出的文件。备份里带上聊天文件和解析出的文字。因为时间从系统提示词移到了附注，发给模型的内容和 0.9.1 不再逐字一样。
