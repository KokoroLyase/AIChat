# 智信 0.4.2

2026-11-09

- 聊天信息新增“消息免打扰”：开启后不再弹出这个联系人的回复通知，未读数、聊天列表预览和回复照常。
- 聊天信息新增“设置当前聊天背景”：从相册选一张照片作为这个聊天的背景，可以更换或恢复默认。背景只保存在本机，不发给模型。
- 联系人详情新增“温度参数”，按请求里实际生效的值显示，模型固定温度或不发送时会注明；“思考”改为“思考强度”。
- 联系人详情去掉“编辑”按钮，改为“记忆”上方的“朋友资料”，点击进入编辑联系人页，下方小字列出可以编辑的项目。
- 编辑联系人页的“系统提示词”改为一行，显示开头两行，点进去单独一页编辑；改完回到编辑页点“保存”生效。
- “我”页的“设置”改为“模型服务”“通用设置”“数据管理”“关于 APP”四个入口，点进去是各自的设置页，原有设置项都在。

- 修改已保存服务商的地址又没有填新 Key 时，保存、获取列表和手动添加模型前会先确认 API Key 会发给新地址。
- 新建联系人的预填人设不再提到微信；已有联系人保存的文字不变。

数据库升到 v4、备份格式升到 v4，旧数据和旧备份恢复后默认不免打扰、没有聊天背景。删除聊天或联系人时一并删除聊天背景；清空聊天记录保留免打扰和背景。备份包含聊天背景。已有联系人的模型请求内容不变。
