# 智信 0.6.0

未发布

- 新增“主动聊天”：开启后，联系人会根据时间和你们的聊天，在你没有操作时自己来找你。**默认关闭**，新联系人和升级前已有的联系人都要在“朋友资料”里手动开启；可以选频率：偶尔、适中（默认）、频繁。
- **开启后会自动消耗 API 额度。** 每次检查到合适的时机，App 会把这个联系人的人设、记忆和最近的聊天记录发给它所用的服务商，由模型决定要不要找你；模型决定不发、请求失败也各算一次调用。第一次开启时会弹出说明，并申请通知权限。
- “我”页新增“主动聊天”：可以设置免打扰时段（默认 23:00～7:00，这段时间不调用模型）和每日调用上限（默认 20 次，所有联系人合计，第二天恢复）；还能看到今日已用、最近一次检查的时间、后台任务有没有注册，以及每个开启的联系人现在是否暂停和原因。
- 联系人连续 2 次主动找你都没有得到回复，就会暂停，你再发消息后恢复。
- 约定时间：对开启了主动聊天的联系人说“明早 7 点叫我”“下午 3 点提醒我开会”，联系人会记下时间，到点主动发消息。约好的提醒不受免打扰时段限制，但占每日调用次数。
- 主动消息和普通回复一样按“回复偏好”分条、带间隔出现，送达时才更新聊天列表和通知，点通知进入聊天。聊天开了“消息免打扰”时，联系人照常会主动发消息，只是不弹通知。主动消息不能“重新生成”。
- 用量统计里单独标出主动聊天用掉的 token。

**后台不保证准时：** 主动聊天靠系统的后台任务触发，大约每 15 分钟检查一次，没有使用精确闹钟，也不申请新的权限。系统省电、限制后台，或 App 被强制停止时，主动消息和约好的提醒可能晚很多才来，甚至不来；回到 App 时会补查一次，晚了超过 12 小时的提醒不再发。在“我 → 通用设置”关闭电池优化、在系统设置里允许自启动，可以减少这种情况。

**升级后的变化：** 升级后主动聊天对所有联系人都是关闭的，不会有任何后台调用，普通聊天的请求内容和 0.5.0 完全一样。开启主动聊天的联系人，普通聊天的系统提示词里会多一段“怎么记下约定时间”的说明（几十个 token）。

数据库升到 v6、备份格式升到 v6，备份包含联系人的主动聊天开关和频率、免打扰时段和每日上限；今日已用次数、暂停状态和约好的提醒只属于这台手机，不随备份。0.5.0 及更早的备份恢复后，联系人的主动聊天都是关闭的。
