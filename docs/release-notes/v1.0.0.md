# 智信 1.0.0

2026-11-16

1.0.0 是第一个稳定版。这一版不加新功能：用真实的服务商（DeepSeek、Xiaomi MiMo、MiniMax、MinerU）把 0.1.0～0.9.2 的功能和界面逐项测了一遍，修了测出的问题。

- **翻译更准**：翻译不再跟联系人的温度，固定用较低的 0.3（模型的可调范围不含 0.3 时取最接近的值）；要翻译的文字前面也写明“只翻译、不要回答”。之前用 MiMo 并关掉思考时，温度高会翻出乱码，问句会被当成问它而直接回答，现在都会老老实实翻译。
- **DeepSeek 试听有声音了**：语音合成选 DeepSeek 时，选音色页点“试听”之前没有声音、一直显示“播放中”，现在能正常放；手机放不出来时提示“试听失败”，不再卡住。语音消息本来就正常。
- **发语音后能看到回复**：停在聊天底部发语音时，联系人的回复有时落在屏幕下面，也没有“新消息”浮标，现在会跟着滚到底部。
- **提示里的设置路径**：两条关于文件解析的提示写成了“我 → 设置 → …”，改为实际的“我 → 模型服务 → 文件解析”。
- **读屏**：录音浮层的两个按钮，TalkBack 之前念“✓”“✕”，按钮下面的字又念一遍，现在念“完成”“取消”。
- **特大字体**：系统字体调到最大再选 App 的“特大”时，底部“智信”上有未读红点会把这一格撑高、三个字不齐，输入栏“发送”两个字的下半截被切掉，都已修正。标准字号下界面不变。

**费用和隐私：** 没有新增权限，也没有新增要连接的服务器。翻译请求的内容变了（多了一句“只翻译、不要回答”，温度固定），费用基本不变。隐私说明定稿，见仓库里的 `docs/privacy.md`。

**升级后的变化：** 数据库和备份格式不变（v11），0.9.2 和 1.0.0 导出的文件可以互相恢复。

**已知问题：**

- 转动屏幕时，打开着的对话框和底部菜单会关掉，要重新打开；正在填的表单和聊天草稿不受影响。
- 把另一台手机导出的同一份备份“合并”恢复两次，那台手机上的联系人会重复出现一次，删掉多出的即可。
- 系统字体最大、App 选“特大”时，未读红点会盖住大半个“智信”图标（红点里的数字跟着字体放大）。
- 部分手机（如 HyperOS）默认会冻结后台的 App：主动聊天和约好的提醒可能等你回到 App 才发出，需要在系统设置里允许自启动、关闭电池优化。
