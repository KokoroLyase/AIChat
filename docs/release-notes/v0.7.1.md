# 智信 0.7.1

未发布

- 新增本机语音：在“我 → 语音消息”的语音合成、语音识别列表最上面有“本机”一组，不需要 Key 和地址，选用后文字和录音不离开手机，也不计入用量统计。
- **系统语音（本机）**：用手机自带的语音合成引擎把联系人的回复合成成语音。只用不需要联网、已经装好的中文音色；音色在这一页选，联系人单独填的音色是这里列出的名称时用联系人的。语气和风格要求不生效。手机没有语音合成引擎或没有中文音色时不能打开，页面会说明原因，点“语音引擎”可以打开系统的文字转语音设置。
- **离线识别（本机）**：在手机上把你的语音转成文字。识别模型（SenseVoice Small，支持中文、粤语、英语、日语、韩语，自带标点）不在安装包里，要用时在“离线识别”页下载：约 239.5 MB，从魔搭社区（ModelScope）下载，建议用 Wi-Fi。下载在后台进行，有进度通知，可以暂停、之后从断点继续；下载完按固定的校验值核对，不对就删除。模型计入“存储空间”，可以在“离线识别”页删除，不随导出文件备份。只支持 64 位 ARM 手机。
- 识别时要占用几百 MB 内存，较旧的手机可能要等几秒。识别不出文字时和服务商识别失败一样，这一轮不会发给联系人，可以重试。
- 安装包从约 7.2 MB 变成约 14.9 MB（多出的是离线识别的运行程序）。
- “开源许可”加上 sherpa-onnx、ONNX Runtime 和 SenseVoice Small 模型。

**升级后的变化：** 数据库和备份格式不变（仍是 v7），0.7.0 的备份照常恢复。选用的本机来源会随备份恢复，但离线识别模型和系统音色不在备份里，换手机后要重新下载模型、选音色。没有选用本机来源时，语音和聊天的行为与 0.7.0 相同。
