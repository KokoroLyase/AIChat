# 智信 0.9.0

（未发布）

- **多选**：长按消息点“多选”，勾选多条后可以一起复制、收藏或删除。复制时每条一行、按时间排列，通话复制成完整的通话内容；删除和逐条删除一样，语音和通话的录音一起删掉。等待回复中的消息和正在进行的通话不能选。
- **复制通话**：长按通话消息有“复制”，复制这次通话的时间、时长和每一句话。
- **收藏**：长按文字、语音或打完的通话点“收藏”（多选时也可以），在“我 → 收藏”里查看、搜索、播放和复制。收藏单独保存一份（语音和通话的录音也复制一份），删除原消息、清空聊天、删除联系人都不影响；删除收藏时只删它自己的文件。图片和等待中的消息不能收藏。
- **引用**：长按文字或有转写的语音点“引用”，输入栏上方出现引用条，下一条文字或语音会带上它（发图片不带，引用条留着）。气泡下面显示“名字：内容”，点它跳到原消息；原消息删了时提示“原消息已删除”。联系人会知道你在回复哪一句。
- **翻译**：长按文字或有转写的语音点“翻译”，中文翻成英语，其他语言翻成中文；译文显示在气泡下面，长按可以复制或隐藏，翻过的再点不会重新请求。失败时显示原因，点一下重试。
- **长按菜单**：键盘开着时长按消息，键盘不再被收起；菜单左右离屏幕边缘留出空隙，各项等宽排列，每行项数尽量均匀，不会只剩一项单独一行。

**费用和隐私：** 翻译会把这条消息的文字发给这个联系人正在用的模型服务商，按它的规则收费，用量页单列“翻译”，不占主动聊天的次数。引用会让发给模型的那条消息多一行被引用的话（最多 100 字）。收藏是保存在手机上的新数据，计入存储空间，导出时可以单独选择。

**升级后的变化：** 数据库和备份格式升到 v10，0.8.0 的备份照常恢复；0.9.0 导出的文件，0.8.0 及更早的版本打不开，会提示先升级。没有引用的消息，发给模型的内容和 0.8.0 完全一样；译文不会发给模型，也不进记忆。
