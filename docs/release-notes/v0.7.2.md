# 智信 0.7.2

（发布日期待定）

- **记忆更精炼**：联系人的记忆分成“核心记忆”和“近期记忆”两组。核心记忆记着现在仍然成立的重要事实，近期记忆是最近几段聊天的总结；近期记忆多了，最早的几条会和核心记忆一起整理成新的核心记忆。每次聊天带的记忆合计最多约 1500 token，不再随上下文上限变长；总结只记重要内容，闲聊不再生成记忆。升级前积累的记忆会在之后几次回复里自动整理（整理会用联系人的记忆模型，计入记忆用量）。核心记忆可以在记忆页编辑和删除。
- **导出和恢复可以选择内容**：在“我 → 数据管理”导出时，可以只选联系人、聊天记录、联系人记忆、用量统计、全局记忆、模型配置、回复偏好、主动聊天设置、语音消息设置、个人资料和外观中的几项，默认全选；API Key 只跟着模型配置导出。恢复时也能只选文件里的某几项，没选的内容保持本机原样。覆盖恢复前不再单独问是否保留本机的全局记忆，不想换就在恢复内容里不选它。
- **更多语音服务商**：语音合成新增火山引擎（豆包）、阿里云百炼（千问）、MiniMax、Fish Audio，硅基流动也能合成；语音识别新增火山引擎（豆包）、阿里云百炼（千问）。语气和风格要求现在对 Xiaomi MiMo、火山引擎、阿里云百炼和硅基流动都生效。
- **选音色**：服务商页和联系人编辑页可以打开音色列表，按名称搜索、分组查看、点“试听”听一句（试听会调用服务商，可能产生少量费用，不计入用量统计）。没在列表里的音色仍可手填。
- 阿里云百炼（语音和聊天）的预置地址改成业务空间专属地址，新建时要把地址里的 {WorkspaceId} 换成自己的业务空间 ID；已保存的连接不受影响。

**升级后的变化：** 数据库和备份格式升到 v8，0.7.1 的备份照常恢复（旧记忆都算近期记忆）。0.7.2 导出的文件，0.7.1 及更早的版本打不开，会提示先升级。新加的语音服务商只按官方文档实现，开发时没有调用过真实服务商，使用中遇到问题请反馈。
