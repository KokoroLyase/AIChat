# 智信 0.9.1

（草稿，未发布）

- **新图标**：App 图标换成新设计：绿色底上一个白色线条的气泡，里面是五道声波；主题图标和通知图标也一起换了。App 里的图标全部重画成同一种细线风格，底部标签栏选中时是实心的。
- **动画**：新收到和刚发出的消息轻轻浮现（往上翻看历史时不播），发出消息后列表平滑上移；表情和“+”面板像键盘一样升起、收起；长按菜单从气泡处弹出，带一个指向气泡的小三角，被按住的气泡变暗，点了以后淡出；底部菜单从下往上滑出，背景渐暗；对话框淡入、关闭时淡出，背景跟着变暗、变亮；右上角“+”菜单从角上展开；多选时勾选圈滑入，顶栏、输入栏和操作栏渐变切换；选音色、回复偏好、崩溃日志详情像其他页面一样从右边推入；转文字、译文、思考过程、“高级”设置和引用条展开、收起时平滑过渡；录音浮层和“N 条新消息”淡入淡出；聊天列表里的会话换位置、删除时平滑移动。系统设置里关掉动画后，通话的波纹、声波、跳动的点不再动。
- **大字体和窄屏**：
  - 标题放不下时先缩小字号；“我”页的名字和版本号、联系人详情的名字和服务商、聊天信息里的名字不再被截断。
  - 通话中字体很大时，字幕卡片整张露出来。
  - 字体调到特大时图标也跟着变大一些。
  - 分段选择项放不下时分成几行；列表右侧的值放不下时换到下一行；语音条的秒数、“语音通话”不再折行；长语音放不下时先变短，旁边的“转文字”不再被挤成一字一行（实在放不下时不显示，长按菜单里也有）。
- **界面统一**：对话框里两行以上的说明改为左对齐；列表里的“恢复默认”“下载”这类动作用蓝色、靠左，“删除”“清空”这类用红色、居中；通话详情里“没有识别出文字”的那句改成灰色占位样式。
- **修正**：聊天列表停在最顶上时，收到新消息的会话排到第一位后能直接看到（以前要往下拉才出现）；从“选音色”“回复偏好”返回联系人编辑页、从“选音色”返回语音服务商编辑页时，页面停在原来的位置（以前回到顶部）。

**费用和隐私：** 没有新增要连接的服务器，也没有新的本地数据；发给模型的内容和 0.9.0 完全一样。

**升级后的变化：** 数据库和备份格式不变（仍是 v10），0.9.0 和 0.9.1 导出的文件互相都能恢复。
