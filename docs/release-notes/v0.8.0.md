# 智信 0.8.0

2026-11-13

- **语音通话**：在联系人资料“发消息”下面，或聊天页“+”里“相册”“拍照”后面，点“语音通话”就能和联系人打电话。你说完一段话（停顿约 0.8 秒），这段话会识别成文字发给联系人，联系人的回复一句一句合成出来、边合成边播放，放完接着听你说。通话用这个联系人实际的语音识别和合成来源（单独选的用不了时不能打，不会换成全局的），系统语音和离线识别也能用。通话接在原来的聊天后面，不新开上下文，之后的聊天和记忆都会带上通话里说过的话。
- **通话页**：显示时长和现在的状态（在听、正在识别、对方正在想、对方在说），可以收起字幕；静音、免提和听筒（不开免提时连着耳机就从耳机出声）、挂断。你在说的时候可以点“说完了”马上发出，联系人在说的时候可以点“打断”。按返回键不会挂断，回到桌面或锁屏时通话继续，通知栏显示“正在通话”，可以点按回来或直接挂断。
- **通话消息**：聊天里显示一条“通话时长 03:21”的通话消息，点进去能看这次通话的每一句、播放完整通话（可以暂停、从停下的地方接着放，进度条拖到哪里就从哪里放），也能单独放某一句。通话的录音和合成的语音保存在手机上，计入存储空间；删除通话、清空聊天、删除联系人时一起删除；导出时跟着“聊天记录”。
- **判断说话**：用随安装包提供的 Silero VAD 模型（约 0.6 MB，不用另外下载）判断你是否在说话；不支持的手机改用音量判断，环境吵时可以点“说完了”。只保存说话的那几段，不保存中间的静音。
- 失败（没听清、联系人没回上来、断网）时通话页会提示，然后接着听；连续 3 轮失败、单次超过 60 分钟、5 分钟没人说话、来电时会自动挂断。正在通话的联系人不会主动发消息，通话中这个聊天的输入栏换成“回到通话”。

**费用和隐私：** 通话中每说完一段都会请求一次语音识别、一次联系人的模型和几次语音合成，按各服务商的规则收费，用量分别记在聊天、语音识别和语音合成里。第一次通话前会说明录音和文字发给谁。通话需要麦克风权限，并新增“麦克风类前台服务”权限，只在通话期间使用。

**修复：** 0.7.0 到 0.7.2 导出的备份里有语音服务商（语音合成或语音识别）时，恢复会提示「不是有效的智信备份文件」，现在能正常恢复。

**升级后的变化：** 数据库和备份格式升到 v9，0.7.2 的备份照常恢复。0.8.0 导出的文件，0.7.2 及更早的版本打不开，会提示先升级。不在通话时，发给模型的内容和 0.7.2 完全一样。开发时没有调用过真实的服务商，通话的延迟要看各家服务商的速度，使用中遇到问题请反馈。
