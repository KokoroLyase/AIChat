智信 0.3.0：长期记忆与多服务商。

- 上下文预算：每个联系人可以设置 token 上限（默认 4000），系统提示词、记忆和聊天记录合计不超过它，超出时丢弃最早的消息。代替原来的「上下文条数」，已有联系人按「条数 × 200」自动换算
- 长期记忆：较早的聊天自动总结成记忆，每次请求都带上。在联系人详情的「记忆」里可以查看、编辑、删除。总结会额外消耗少量 API 额度，可以在联系人编辑页关闭「自动记忆」
- 老聊天不自动回溯：升级后从当前的聊天开始总结，更早的聊天可以在记忆页手动「总结更早的聊天」，每次一批
- 多服务商：可以添加任意兼容 OpenAI 格式的服务商（名称、Base URL、Key），从接口拉取模型列表，接口没有列表时可以手动添加模型；每个模型可以标记是否支持图片、是否支持思考。Base URL 只支持 https
- 联系人可选服务商：编辑页先选服务商，再选模型
- 用量统计：在「设置 → 用量统计」里按天、按联系人查看 token 用量，记忆总结单独标出
- 应用内更新：在 App 里下载安装包，用 SHA-256 校验并核对签名后拉起系统安装；下载或校验失败时可以在浏览器中打开发布页面
- 导出和恢复：服务商、记忆和用量也会导出和恢复；所有服务商的 Key 默认不导出，勾选后用密码加密。旧版本导出的备份可以直接恢复

需要 Android 14 及以上。从 0.2.0 或 0.1.0 直接覆盖安装即可，已有的 DeepSeek 设置和联系人会自动保留。这个版本还不能应用内升级到自己：从 0.2.0 升级要到发布页面下载，之后的版本才能在 App 内更新。
