# 智信 0.7.0

2026-11-12

- 新增语音消息（调用语音服务商 API 的部分）。在“我 → 语音消息”里分别设置**语音合成**和**语音识别**的服务商：预置 Xiaomi MiMo（合成和识别）和硅基流动（识别），也可以自定义。两种请求格式都支持：聊天接口带音频（按 MiMo 文档）和 OpenAI 标准音频接口。Key 和大语言模型的一样加密保存，只发给它自己的地址。服务商按自己的规则收费，App 不做试听。
- 发语音：点输入栏最左边的按钮切到“按住 说话”。按住录音，最长 60 秒，不到 1 秒不发；松开发送，上滑到左边取消、右边转成文字放进输入框。读屏时可以点一下开始、再点发送。第一次使用时会说明录音要发给哪个语音识别服务商，并申请麦克风权限。
- 发出的语音先识别成文字，联系人看到的是这段文字。识别失败时这一轮不会发给联系人，点红色感叹号可以再识别一次。
- 录音转文字：输入框里的麦克风按钮，说完点“完成”，识别出的文字放进输入框，改完再发。
- 联系人回文字还是语音由“消息发送类型”决定：**跟随**（默认，你发语音就回语音）、文字、语音（总是回语音，主动聊天的消息也是）。全局默认在“我 → 语音消息”，每个联系人也可以在“朋友资料”里单独指定，还能设音色、语气和风格（语气和风格只有 MiMo 这类服务商支持）。
- 语音回复先生成文字，再合成语音，合成好才出现；较长的回复会分成一两条语音。合成失败时那一条改发文字，不会再请求模型，也不会卡在“对方正在输入”。没设置语音合成时一律回文字。
- 语音条：宽度随时长变化，对方没听过的有红点，旁边的“转文字”可以显示文字。点一下播放，放完会接着放下一条没听过的。长按可以复制文字、删除、听筒播放、后台播放（回到桌面也接着放）、转文字或取消、连续朗读。
- 语音会计入“存储空间”，删除消息、清空聊天、删除联系人时一起删除，随导出文件备份。用量统计里单独列出语音合成的字数、秒数和语音识别的秒数，不算进 token。
- 新权限：麦克风（用到时才申请）、媒体播放前台服务（只在后台播放时运行）、修改音频设置（听筒播放时切换到听筒）。

**升级后的变化：** 不用语音时，聊天请求的内容和 0.6.0 完全一样。数据库升到 v7、备份格式升到 v7；旧消息都不是语音，联系人都用全局的消息发送类型。恢复 0.6.0 及更早的备份时，本机已经设好的语音服务商和语音设置保留。

系统自带的语音合成和本机离线识别计划在 0.7.1。
