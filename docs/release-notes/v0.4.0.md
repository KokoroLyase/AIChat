# 智信 0.4.0

这一版不加新玩法，主要让 App 更稳、聊天记录再多也不卡，并保护好离开手机的导出文件。

- 聊天记录改成分段加载，很长的聊天也能顺畅打开和滚动。
- 有未读时，打开聊天会定位到第一条未读；从搜索进入会定位到那条消息并高亮。
- 翻看历史时收到新消息，页面不再跳走，右下角会显示“↓ N 条新消息”，点一下回到底部。自己发消息还是会回到底部。
- 导出时可以设置密码，设了密码就会加密整个文件，保存为 `.aichat`。包含 API Key 时必须设置密码。
- 恢复成功后，会立即删除恢复前的临时备份和解密临时文件；恢复失败仍会自动撤销。以前版本恢复时留下的临时备份，升级后第一次启动时也会清除。
- 新增“设置 → 数据 → 存储空间”：查看聊天图片、头像、崩溃日志、缓存和数据库的占用，可以清理缓存和没有被使用的孤立文件。清理前会先告诉你数量，回复或恢复进行中不能清理。
- 新增“设置 → 关于 → 崩溃日志”：只保留最近 20 份，保存在本机，不包括异常说明、聊天内容和 API Key；只有你主动分享才会离开手机。长按 App 图标也能打开，App 打不开时可以用这个入口。

**升级前请注意：**

- 从 0.3.1 覆盖安装即可，联系人、聊天记录、记忆和 API Key 都会保留。本版没有数据迁移。
- **0.3.1 读不了新的加密导出文件**，会提示文件无效。手上如果还有 0.3.1 设备要恢复，请导出时不设密码，或者先升级那台设备。
- **忘记导出密码就无法恢复**，这个文件里的任何数据都取不回来。
- **卸载 App 会清空所有本地数据**，卸载后只能靠导出文件找回。
- 以前导出的备份（明文 zip 和只加密 API Key 的 zip）继续能恢复。
- 加密文件在部分手机的系统选择器“最近”页里看不到，请到导出时保存的文件夹里找。

加密只针对两样东西：API Key 和设了密码的导出文件。手机上的聊天记录、图片和设置依靠系统的应用隔离和全盘加密保护，App 没有另外加密。

这一版没有改发给模型的请求内容。七家预置服务商仍然只用模拟接口测试过，没有用真实服务商逐家验证。

需要 Android 14 及以上。
