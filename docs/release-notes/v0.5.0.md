# 智信 0.5.0

未发布

- “我”页新增“全局记忆”：按类别、主题整理关于你自己的信息，每条可以单独开关、编辑、删除和调整顺序。开启“使用全局记忆”的联系人每次请求都会带上已启用的条目。这些内容会发给每个开启它的联系人所用的服务商，联系人用的服务商不同时，同一份内容会发给多家；页面上写明了会发给哪些服务商和大致占用的 token。
- “我”页新增“回复偏好”：联系人等你说完（默认 3 秒内没有新消息）再回，一次分 1～5 条发，每条 14 字左右，条与条之间隔 3～10 秒，默认去掉句尾的“。”和“，”（保留“？”“！”“…”）。这些都可以调整。
- 编辑联系人新增“使用全局记忆”“使用回复偏好”两个开关；系统提示词一行下面显示它（含全局记忆、记忆和回复偏好）合计占用多少上下文，超过一半时提醒。
- 回复改为可靠投递：模型回复后先保存，到时间再逐条出现；App 被关掉后重新打开，没送完的会接着送，不会丢，也不会重复。送完一条更新一次通知，同一次回复只响一次；开了消息免打扰的联系人照常不响。切到后台时投递会继续，一次回复的几条隔得较久时，通知栏会短暂显示“正在接收消息”。
- 联系人还在一条条发的时候你又发了消息，已经生成的会先发完，再回复你的新消息。

**升级后已有联系人的变化：** 新功能对新联系人和已有联系人都默认开启。开启后每次请求会多带上回复偏好的要求（以及你写的全局记忆），请求内容和 token 用量会比 0.4.2 多一些，联系人的说话方式也会变成短句、分条、带间隔。不想要的话，可以在编辑联系人里关掉这两个开关，或在“全局记忆”“回复偏好”页里一次关掉所有联系人的；两个都关掉后，请求内容和 0.4.2 完全一样，分条显示按原来的设置。

- 修复：API Key 里混进中文、全角符号或空格时，消息会一直停在“对方正在输入…”；现在会提示 Key 无效、可以重试，服务商设置页也不会再保存这样的 Key。

数据库升到 v5、备份格式升到 v5，备份包含全局记忆、回复偏好和联系人的两个新开关。旧数据和旧备份恢复后，联系人默认使用全局记忆和回复偏好，原来的分条显示设置保留；0.4.2 的免打扰和聊天背景照常保留。
